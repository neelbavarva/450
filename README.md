## About

This repository tracks my progress through the 450 DSA sheet, a curated list of data structures and algorithms questions that covers almost every topic asked in coding interviews. Each topic folder has the sheet's problems, and many also have concept notes and additional practice problems from LeetCode, GeeksforGeeks and InterviewBit.

## Folder layout

Topic folders use these subfolders, depending on what each topic needs:

```
Topic/
├── 450/        # problems from the 450 sheet
├── Concept/    # concept notes and the classic problems for that pattern
├── All/        # extra practice problems
└── README.md   # notes and a problem list for the topic
```

## Running a solution

Each problem has its own folder, and most solutions are written in the format of the online judge the problem comes from, such as GeeksforGeeks or LeetCode: a `Solution` class containing the required method, without a `main` method. To run one, paste it into the problem's online editor, or add your own `main` method and imports.
